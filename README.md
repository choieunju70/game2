# Game 02 · 키티 블록

헬로키티 얼굴을 Canvas로 그린 블록을 사용하는 기본 테트리스 팬 게임입니다. 공식 Sanrio 제품은 아닙니다.

- 10×20 보드, 7종 블록, 무작위 7-bag, 다음 블록 및 착지 위치 표시
- 방향키 좌우 이동, ↑ 회전, ↓ 빠른 내리기, Space 바로 내리기, P 일시정지
- 모바일 터치 버튼 지원
- 줄 제거: 1/2/3/4줄 100/300/500/800점 × 레벨
- 10줄마다 레벨 상승, 속도 증가. 최고 점수는 해당 브라우저에 저장
- 게임 종료, 다시 시작, 창이 숨겨지면 자동 일시정지

## 실행 및 배포

설치나 빌드 없이 index.html을 열거나, 이 폴더에서 `python3 -m http.server 3000`을 실행하세요.
Vercel에서 저장소를 Import하고 Framework Other, Build Command 비워두기, Output Directory `.`을 사용하세요. 환경 변수는 필요 없습니다.

캐릭터 권리는 Sanrio에 있습니다. 상업적 사용을 위한 라이선스는 포함하지 않습니다.
